# Example CUI artifacts

Filled-in versions of the files that drive the CUI. The milestone, blueprint and command
examples come from a small project called OrderLens; the registry examples from a mail app.
They are a shape reference for the `pf-milestones`, `repo-blueprint` and `feature-registry`
skills — copy the structure, not the content.

- `product-functions.yaml` — Product Function milestones with acceptance criteria
- `blueprint.yaml` — locked directory layout, boundary rules and entry points
- `commands.yaml` — the searchable command catalogue
- `features.yaml` — the feature registry: IDs, milestones and test plans
- `exceptions.yaml` — features verified some other way than an automated test

Your project's real versions live one directory up, in `.cui/`.
